Disaster Recovery & Restore Guide

To restore a mail server snapshot on this host or a new server:

  1. Extract the backup archive to a temporary directory:
    tar -xzf /backups/mail-TIMESTAMP.tar.gz -C /tmp/restore
  2. Restore PostgreSQL database tables and credentials:
    docker exec -i mailserver-db pg_restore -U mailuser -d mailserver < /tmp/restore/database.dump
  3. Restore mailbox email storage (Maildir format):
    tar -xzf /tmp/restore/maildata.tar.gz -C /var/mail/vhosts/
