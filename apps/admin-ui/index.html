DNS Configuration & Verification

example.com

Add the following DNS records to your domain's DNS provider (e.g. Cloudflare, Route53, Namecheap, GoDaddy):

1. OWNERSHIP VERIFICATION (REQUIRED) TXT Record
Host / Record Name:
_mail-admin.example.com
Record Value / Token:
...
2. INCOMING MAIL ROUTING MX Record
Host: @
Priority: 10
Points to (Mail Server):
mail.example.com
3. EMAIL AUTHENTICATION (SPF) TXT Record
Host: @
Value:
v=spf1 mx ~all
4. DKIM SIGNING (REQUIRED) TXT Record
Host / Record Name:
mail._domainkey.example.com
Value:
v=DKIM1; k=rsa; p=...
5. DMARC POLICY TXT Record
Host:
_dmarc.example.com
Value:
v=DMARC1; p=quarantine;
